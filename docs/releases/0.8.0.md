# 0.8.0

支持实时输出正文和思考内容，并补齐会话权限模式切换。继续使用 DeepSeek Harness `0.2.2-rc.1`，支持 ACP v1 和实验性 v2。

- 回复生成期间，客户端会逐段收到文字。正常结束、取消和失败时，不会再次追加已经显示的全文；重试会使用独立消息。
- 支持在客户端选择只读、工作区写入和完全访问。选项来自 Harness，切换会保存到当前会话，并同步后续的权限或可选项变化。
- 恢复旧会话时保留已经保存的权限，不用启动时的默认值覆盖它。自定义权限组合会显示为 Custom；没有提供权限服务的配置不显示此选项。
- v2 历史回放会恢复正文、思考以及取消或失败时已显示的内容；继续对话、运行中切换权限和关闭会话共用原来的生命周期处理。

安装后重启 ACP 客户端。使用固定版本 `npx` 的配置，将版本改成 `0.8.0`。

```sh
npm install -g @dumbo-ai/dsh-acp@0.8.0
dsh-acp --version
```

## 客户端接入

v1 接收 `agent_message_chunk` 和 `agent_thought_chunk`，按消息追加内容。v2 同时接收这些增量和 `agent_message`、`agent_thought` 最终快照；同一消息的快照替换已有内容，不能把快照再次追加到增量后面。

权限通过 `mode` 配置选项读取和切换，执行限制仍由 Harness 负责。完全访问采用 Harness 的 `never` 审批策略，不弹出确认；明确要求审批的工具会被拒绝。

助手消息现在采用可从历史记录重建的标识，思考内容有独立标识。保留了 0.7.1 消息缓存的客户端，升级后需要从 `replayFrom: { "type": "start" }` 重新建立一次历史；用户消息标识保持不变。v1 仍按原来的方式恢复上下文，不回放历史。

## 验证

模型使用可重复的测试响应，Harness、工具执行、权限与会话存储使用真实实现，没有调用真实模型 API。

- 类型检查、lint、构建和 53 项测试通过，覆盖实时正文与思考、权限切换、取消、失败重试、运行中重连、关闭与断连恢复，以及旧版普通会话分支。
- 使用 npm 已发布的 `0.7.1` 创建只读、工作区写入和完全访问会话，分别通过新版 ACP v1/v2 恢复；六种组合都保留权限、模型、推理强度和上下文，继续对话可实时输出。
- 在空目录安装最终 npm 包，版本和命令入口正确，34 项 ACP 进程测试通过。
- [ACP 兼容性测试工具](https://github.com/agentclientprotocol/acp-tck/tree/b7f40fb3c003c45926547be5a1f7e2b374035815)：v1 为 57 项通过、17 项跳过；v2 为 97 项通过、28 项跳过；均为零失败。工具未触发的权限阻塞场景由本仓库进程测试覆盖。
