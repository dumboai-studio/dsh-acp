# 0.7.1

将 DeepSeek Harness 升级到 `0.2.2-rc.1`，继续支持 ACP v1 和实验性 v2。

- 在客户端切换模型或思考强度时，当前轮次会用原模型完成工具调用及后续回复。新的选择从下一轮生效，正常关闭后重新打开会话也能恢复。
- ACP 客户端继续显示当前会话的任务清单和完成进度，数据来自 Harness 新版的待办列表接口。
- 旧版创建的普通分支可以从历史列表里找到并继续对话。由子代理执行的会话仍由父会话管理。

全局安装用户运行以下命令，然后重启 ACP 客户端。使用固定版本 `npx` 启动的客户端，将包版本改为 `0.7.1` 即可。

```sh
npm install -g @dumbo-ai/dsh-acp@0.7.1
dsh-acp --version
```
